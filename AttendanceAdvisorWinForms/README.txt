ATTENDANCE ADVISOR — WINDOWS FORMS

Project: C# WinForms / .NET 8
Target: Windows 10/11 with .NET 8 SDK installed

HOW TO OPEN
1. Install Visual Studio 2022 with the .NET desktop development workload.
2. Open AttendanceAdvisor.csproj.
3. Press F5 / Start.

FEATURES
- Dashboard with visual attendance chart
- 75% minimum and 90% target indicators
- Subject-wise attendance input
- IV ECE-B VII Semester timetable from the supplied SRM timetable
- OD / Medical Leave simulator
- Attendance Advisor chat-style calculator
- Warnings when projected attendance falls below 75% or 90%

SUBJECT MAPPING FROM SUPPLIED TIMETABLE
A: Behavioural Psychology
B: Wireless Communication and Antenna Systems
C: Computer Communication and Network Security
D: Semiconductor Memory Design
E: Scripting Language for Electronic Design Automation
F: Machine Learning for All
LAB: Computer Communication and Network Security Lab

NOTE
The advisor is a local rule-based calculator, not a cloud AI model. It uses the values entered in the app and does not send student data to an external service.
